# 정산 포털 정책 로그 점검 결과

## 결론

- 정책 결정과 앱 처리 결과가 다른 요청 3건과 정책 판단 기록이 없는 앱 처리 요청 1건을 확인했으며, 점수 규칙 완화 시 정상 업무의 불편은 줄지만 위험 요청을 충분히 차단하지 못하는 사례가 생깁니다.

## 근거

- 3-1에서 집행 누락(결정한 것보다 약하게 처리한 경우)은 101·108번의 2건이며, 과집행(결정한 것보다 강하게 막은 경우)은 112번의 1건입니다.
- 3-1의 요청 201은 정책 로그에 없지만 앱에는 200으로 기록되어 우회(정책 판단 경로를 거치지 않은 접근)가 의심됩니다.
- 4-1의 11건 비교에서 오탐(정상 요청을 추가확인하거나 거부한 경우)·미탐(위험 요청을 거부하지 못한 경우)은 현재 6·0건, A안 0·1건, B안 0·2건, C안 0·2건입니다.

## 권고

- 요청 101·108·112의 처리 로그와 정책 집행 설정을 확인하고, 요청 201의 접근 경로와 정책 로그 누락 여부를 조사합니다.
- 제공된 자료에서 오탐을 없애면서 미탐이 가장 적은 A안을 우선 검토하되, 11번처럼 해외에서 50건 미만을 조회하는 위험 요청을 거부하지 못하므로 보완 기준을 마련하고 추가 자료로 검증합니다.
