# day05 경보 판단

## 이상한 줄

- 줄 번호(여러 개면 모두): 2번, 3번
- 이유: 외부 IP 192.0.2.7에서 내부망(INSIDE)의 DB 서버 3306 포트로 직접 접근한 연결이 방화벽에서 permit 처리되었다. DB는 인터넷에서 직접 접근할 수 없어야 하므로 잘못된 방화벽 허용 규칙이 존재할 가능성이 있다.

## 고친 구성도

```
INTERNET ──── FW ──┬── DMZ
                   │   : WEB (443 open)
                   │
                   └── INSIDE
                       : DB (3306 from WEB only)
```

## 수정한 방화벽 정책

- 인터넷 → WEB 443: 허용
- 인터넷 → DB 3306: 차단
- WEB → DB 3306: 필요한 WEB 서버에서만 허용
- 그 외 불필요한 접근: 기본 차단

## 보안 판단

방화벽 로그에서 외부 IP의 DB 직접 접근이 허용된 사실은 확인되었지만, 실제 DB 로그인 성공이나 데이터 유출 여부는 확인되지 않았다. DB 접근 로그와 인증 로그를 추가 조사해야 한다.
