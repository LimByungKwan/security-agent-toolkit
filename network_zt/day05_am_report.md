### 문제 2-2 · 방화벽 로그에 없는 접속 찾고 조치 보고 평가하기

- (가) 방화벽 로그에 짝이 없는 로그인은 몇 건이고, 번호는 무엇인가요?
  - 쓸 내용: 「… 건 / 번호: …」 번호는 `1, 4, 6` 처럼 숫자로 써도 됩니다
  - 답: 3건 / 번호: 1, 4, 6
- (나) 🔍 방화벽 로그에 없는 접속 중 가장 수상한 것은 몇 번이고, 그렇게 본 근거는 무엇인가요?
  - 쓸 내용: ① 번호 하나 ② 근거 두 가지 이상(시각 · 접속한 IP · 같은 계정의 다른 접속 중에서 골라서)
  - 답: 1번 로그인이다. 퇴사 예정자인 lee 계정이 새벽 03:12에 접속했고, 회사 공인 ip 203.0.113.10이 아닌 192.0.2.88에서 로그인했기 때문에 계정 도용 가능성이 의심된다.
- (다) 담당자 보고에서 **확인된 것**과 **확인하지 못한 것**을 각각 적어 주세요.
  - 쓸 내용: 「확인된 것: … / 확인하지 못한 것: … (두 가지 이상)」
  - 답: 확인된 것: 오전 10:00에 lee 계정 비밀번호를 변경했다. 확인하지 못한 것:03:12 접속에서 문서 열람이나 다운로드가 있었는지, 기존 로그인 세션이 종료되었는지, 실제 접속자가 누구인지는 확인되지 않았다.
- (라) 🔍 확인하지 못한 것을 확인하려면 어느 기록에서 무엇을 봐야 하나요?
  - 쓸 내용: ① 볼 기록 이름 ② 그 기록에서 찾을 것 두 가지(시각 · 접속 IP · 계정 중에서)
  - 답: SaaS 서비스의 활동 기록에서 lee 계정이 03:12 이후 192.0.2.88 IP로 접속해 어떤 문서를 열람하거나 다운로드했는지 확인해야 한다.
- (한 줄) 고객에게 보낼 답을 한 문장으로 적어 주세요.
  - 쓸 내용: 고객이 바로 읽을 수 있는 한 문장(확인된 것과 확인 중인 것을 함께)
  - 답: 퇴사 예정자 lee 계정의 새벽 03:12 외부 접속을 확인해 비밀번호를 변경했으며, 현재 자료 열람·다운로드 여부와 기존 로그인 세션의 종료 여부를 추가 확인해야 합니다.
- 이 교시에서 새로 알게 된 것 하나를 적어 주세요.
  - 쓸 내용: 자유롭게
  - 답: 직원이 외부에서 SaaS에 직접 로그인하면 회사 방화벽에 기록이 남지 않을 수 있으며, 이런 접속은 SaaS의 로그인 기록과 활동 기록을 확인해야 한다는 것을 알게 되었다.

## 4교시 · 구역 규칙 코드

### 문제 4-1 · 규칙 판정 코드 읽고 설명하기

- (가) 함수 `default_policy` · `match_rule` · `judge` 가 각각 무엇을 하는지 적어 주세요.
  - 쓸 내용: 「default_policy: … / match_rule: … / judge: …」 함수마다 자유롭게
  - 답: default_policy: 일치하는 규칙이 없을 때 기본 정책에 따라 통신을 허용하거나 차단한다.
        match_rule: 요청의 출발 구역, 도착 구역, 포트가 규칙과 모두 일치하는지 확인한다.
        judge: 규칙을 위에서부터 검사해 처음 일치한 규칙의 동작과 번호를 반환하고, 없으면 기본 정책을 적용한다.
- (나) `judge` 가 리턴하는 값 두 개는 무엇이고, 어느 줄이 만드나요?
  - 쓸 내용: 「값 ①: … / 값 ②: … / 만드는 줄: …」
  - 답: 값 1: 동작(permit 또는 deny), 값 2: 적용된 규칙 번호, 만드는 줄: return rule[4], rule[0]
- (다) 🔍 `judge` 의 `for` 는 맞는 규칙을 찾으면 바로 `return` 합니다. 같은 요청에 규칙이 둘 이상 맞는다면 어느 규칙이 적용되나요? 왜 `return` 으로 바로 끝내도록 만들었나요?
  - 쓸 내용: ① 규칙이 둘 이상 맞을 때 적용되는 규칙 ② 방화벽이 「첫 번째로 맞는 규칙」을 쓴다는 점과 이어서 `return` 으로 바로 끝내는 이유
  - 답: 규칙표에서 가장 먼저 일치하는 규칙이 적용된다. return을 만나면 함수가 즉시 종료되므로 뒤에 있는 규칙은 검사하지 않는다. 이를 통해 방화벽의 첫 번째 일치 규칙 우선 방식을 구현한다.

### 문제 4-2 · 허용 포트 목록 함수 채우고 흐름 그리기

- (가) 채운 `allowed_ports` 함수를 붙여 넣고, 실행해서 나온 출력 네 줄을 적어 주세요.
  - 쓸 내용: ① 채운 함수 ② 출력 네 줄
  - 답:

```
[443]
[445]
[22, 80, 443, 445, 3389]
[]
```

- (나) `judge` 함수의 흐름을 ASCII 도식(상자 · 화살표)으로 그려 아래 코드 블록에 넣어 주세요.
  - 쓸 내용: 코드 블록 안에 ASCII 도식을 직접 그리기(상자 안은 영어 · 숫자)
  - 답:

```
 [ START ]
             |
             v
    [ Take next rule ]
             |
             v
    [ match_rule() ? ]
          /      \
        Yes       No
         |         |
         v         v
 [ Return action ] [ More rules? ]
 [ and rule no  ]     /    \
         |          Yes     No
         v           |       |
       [ END ]       |       v
                     |   [ Default policy ]
                     |       |
                     |       v
                     |   [ Return action, 0 ]
                     |       |
                     |       v
                     |     [ END ]
                     |
                     +----> Take next rule
```

- (다) 🔍 `allowed_ports` 에서 `result = []` 를 `for` 위에 두는 이유는 무엇인가요? `for` 안에 두면 어떻게 되나요?
  - 쓸 내용: ① `result = []` 를 `for` 위에 두는 이유 ② `for` 안에 두면 달라지는 점
  - 답: 허용된 포트를 하나의 리스트에 계속 누적하기 위해 for 위에서 빈 리스트를 한 번 생성한다. for 안에 두면 반복할 때마다 리스트가 초기화되어 이전에 저장한 포트들이 사라진다.
- (한 줄) 고객에게 보낼 답을 한 문장으로 적어 주세요.
  - 쓸 내용: 고객이 바로 읽을 수 있는 한 문장(요구사항이 지켜졌는지)
  - 답: 제공된 방화벽 규칙을 코드로 검사한 결과, 인터넷에서 DMZ로는 443만, DMZ에서 내부망으로는 445만 허용되는 등 네 가지 요구사항이 모두 충족된 것으로 확인되었습니다.
- 이 교시에서 새로 알게 된 것 하나를 적어 주세요.
  - 쓸 내용: 자유롭게
  - 답: 방화벽은 규칙을 위에서부터 검사해 처음 일치하는 규칙을 적용하며, Python의 for문과 리스트를 이용해 허용된 포트만 모아 검증할 수 있다는 것을 알게 되었다.
