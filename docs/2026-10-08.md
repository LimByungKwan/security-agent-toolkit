# 2026-10-08 (목)

## 오늘 새로 쓴 명령

- `git config`: Git에서 사용할 사용자 이름과 이메일 등 설정을 관리하는 명령어
- `git add`: 변경하거나 새로 만든 파일을 커밋할 준비 단계(Staging Area)에 올리는 명령어
- `git commit`: Staging Area에 올린 변경 사항을 하나의 기록으로 저장하는 명령어
- `git push`: 로컬 저장소의 커밋을 GitHub 원격 저장소에 업로드하는 명령어

## 찾아보고 알게 된 것

**add와 commit과 push의 차이**

- `git add`: 저장할 파일을 선택하는 단계
- `git commit`: 선택한 파일의 변경 사항을 Git 기록으로 남기는 단계
- `git push`: 기록한 커밋을 GitHub에 올리는 단계

즉, `add → commit → push` 순서로 진행한다.

**untracked · tracked · staged의 차이**

- `untracked`: Git이 아직 관리하지 않는 새로운 파일
- `tracked`: Git이 이미 관리하고 있는 파일
- `staged`: `git add`를 통해 다음 커밋에 포함하도록 준비한 상태

`git status` 명령어로 파일의 상태를 확인할 수 있다는 것을 알게 되었다.

## 막힌 것

- `git config --global user.email` 명령어를 입력할 때 마지막 따옴표(`"`)를 빠뜨려 터미널에 `>` 표시가 계속 나타났다.
- 처음에는 오류가 발생한 이유와 명령어 입력을 취소하는 방법을 몰랐다.
- `Ctrl + C`를 누르면 현재 입력을 취소하고 다시 명령어를 작성할 수 있다는 것을 알게 되었다.
- `untracked`, `tracked`, `staged`의 개념과 차이가 처음에는 헷갈렸다.
