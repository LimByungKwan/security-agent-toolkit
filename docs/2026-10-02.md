## 오늘 새로 쓴 명령

- `cd`: 원하는 폴더로 이동
- `ls`: 현재 폴더의 파일과 폴더 목록 확인
- `python -m pip install flask requests schedule ipykernel`: 수업에 필요한 Python 패키지 설치
- `curl --version`: curl이 정상적으로 설치되어 있는지 확인

## 찾아보고 알게 된 것

- VS Code에서 Python 노트북을 사용하려면 Python과 Jupyter 확장이 필요하다.
- Git Bash를 기본 터미널로 설정하면 `ls`, `cd`, `curl` 같은 명령을 수업과 같은 방식으로 사용할 수 있다.
- `.venv`는 프로젝트에서 사용할 Python 가상환경이고, 노트북에서는 해당 환경을 커널로 선택해야 한다.
- 수업 전에 확장, 터미널, 패키지, 가상환경, 현재 작업 경로를 먼저 확인하는 것이 중요하다.
- 자동완성을 끄면 코드를 직접 입력하면서 문법과 명령어를 더 익숙하게 연습할 수 있다.

## 막힌 것

- VS Code에서 `.venv` 가상환경이 제대로 만들어지지 않아 어떤 설정이 문제인지 헷갈렸다.
- 작업 폴더를 신뢰(Trust)하도록 설정한 뒤 가상환경과 Python 기능이 정상적으로 동작했다.
- 터미널에서 현재 위치가 `security-agent-toolkit`인지 `agent_core`인지 확인하는 과정도 아직 익숙하지 않았다.
