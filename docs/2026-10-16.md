서버에서 설정 파일을 고치는 방법:

리눅스 서버에서는 VS Code 같은 그래픽 편집기를 사용하기 어려운 경우가 있다. 이때 터미널에서 `vim`을 사용하면 설정 파일을 직접 열어 수정하고 저장할 수 있다. SSH로 원격 서버에 접속한 상태에서도 사용할 수 있어 서버 관리와 보안 업무에 유용하다.

## 오늘 새로 쓴 명령
- `vim`: 터미널에서 파일을 열고 수정하는 텍스트 편집기
- `i`: 입력 모드로 전환
- `Esc`: 일반 모드로 전환
- `:w`: 파일 저장
- `:q`: 파일 종료
- `:wq`: 저장하고 종료
- `:q!`: 변경 사항을 저장하지 않고 종료
- `dd`: 현재 줄 삭제
- `yy`: 현재 줄 복사
- `p`: 복사한 줄 붙여 넣기
- `u`: 이전 작업 되돌리기
- `/단어`: 특정 단어 검색
- `:%s/옛/새/g`: 파일 전체에서 특정 단어 변경

## vim 으로 한 것
- 입력 모드로 들어가는 키: `i`
- 일반 모드로 돌아오는 키: `Esc`
- 저장하고 나가는 명령: `:wq`
- 저장 없이 나가는 명령: `:q!`
- 지운 것을 되돌리는 키: `u`

## 막힌 것
vim은 일반 모드와 입력 모드가 구분되어 있어 처음에는 언제 글자를 입력할 수 있는지 헷갈릴 수 있었다.

특히 `:wq`와 같은 명령은 입력 모드가 아닌 일반 모드에서 실행해야 한다는 점을 익혔다. 또한 저장하지 않은 변경 사항이 있을 때 `:q`로 종료할 수 없다는 점을 배웠다.
