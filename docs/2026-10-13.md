# 2026-10-13 (화)

## 오늘 새로 쓴 명령
- `cat` : 파일의 전체 내용을 보여 준다.
- `grep` : 파일에서 원하는 글자가 포함된 줄을 찾는다.

## 오늘 쓴 옵션
- `-n` : 찾은 줄에 줄 번호를 붙인다.
- `-c` : 조건에 맞는 줄 수를 숫자로 보여 준다.

## 찾아보고 알게 된 것
`grep`은 긴 로그에서 필요한 기록만 빠르게 찾을 때 사용한다. 보안 담당자가 로그인 실패 기록 등을 확인할 때 유용하다는 것을 알게 됐다.

## 막힌 것
`-c`가 단어가 나온 횟수가 아니라 해당 단어가 포함된 줄 수를 센다는 점이 헷갈렸다.
