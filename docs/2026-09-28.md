## 오늘 새로 쓴 명령
* **pwd**: 현재 위치한 디렉터리 경로 출력 (`/c/Users/User`)
* **ls**: 현재 디렉터리의 일반 파일/폴더 목록 출력
* **ls -a**: 숨김 파일(`.bash_history` 등)을 포함한 모든 목록 출력

## 찾아보고 알게 된 것
* **리눅스/CLI**: 기업 서버/클라우드의 90% 이상이 리눅스라 보안 담당자도 명령어(CLI) 기반의 빠른 대응과 로그 분석이 필수적임
* **GitHub**: 코드 버전 관리, 협업, 보안 스크립트 공유 및 비밀번호/키 유출 감시 용도로 활용됨
* **터미널 & Git Bash**: 윈도우 환경에서 리눅스 스타일의 명령어를 사용하기 위해 Git Bash 설치가 필요함
