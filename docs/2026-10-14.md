## 찾아본 것

**서버에서 로그를 옮기고 백업하는 방법:**

서버에서는 마우스 대신 터미널 명령어를 사용해 파일을 관리한다. 보안 담당자는 로그를 분석하거나 보관할 때 `cp` 명령어로 원본을 복사하고, `mv` 명령어로 파일 이름을 변경하거나 다른 폴더로 옮긴다.

로그 파일은 보안 사고를 분석하는 중요한 증거이기 때문에 원본을 보존하는 것이 중요하다. 따라서 파일을 덮어쓰기 전에 확인하는 옵션을 사용하고, 삭제하기 전에는 파일 경로와 이름을 확인해야 한다.

`rm` 명령어는 파일을 휴지통으로 보내지 않고 삭제하므로 특히 주의해야 한다.

## 오늘 새로 쓴 명령

- **`touch`**: 빈 파일을 생성한다. 이미 존재하는 파일이면 내용을 유지하고 수정 시각을 갱신한다.
  - 예: `touch memo.txt`

- **`cp`**: 파일이나 폴더를 복사한다. 원본은 그대로 남는다.
  - 예: `cp a.log b.log`

- **`mv`**: 파일 이름을 변경하거나 다른 위치로 이동한다.
  - 예: `mv b.log c.log`

- **`rm`**: 파일이나 폴더를 삭제한다. 일반적으로 휴지통을 거치지 않는다.
  - 예: `rm memo.txt`

- **`Tab` 자동 완성**: 파일이나 폴더 이름을 일부 입력하고 Tab 키를 누르면 이름을 자동 완성할 수 있다.
  - 예: `cd mvcp` 입력 후 Tab 키 누르기

## 찾은 옵션

- **폴더째 복사 — `cp -r`**
  - 폴더 내부의 파일과 하위 폴더까지 복사한다.
  - 예: `cp -r backup backup2`

- **덮어쓰기 전에 묻기 — `cp -i`**
  - 같은 이름의 파일이 존재하면 덮어쓸지 확인한다.
  - 예: `cp -i a.log backup/`
  - 확인 메시지가 나오면 `n`을 입력하여 덮어쓰기를 취소할 수 있다.

- **폴더째 지우기 — `rm -r`**
  - 폴더와 내부 파일을 함께 삭제한다.
  - 예: `rm -r backup2`
  - 삭제 전 `pwd`와 `ls`로 현재 위치와 삭제 대상을 확인해야 한다.

## mv 의 두 가지 쓰임

**1. 이름 바꾸기**

`mv b.log c.log`

기존 `b.log` 파일의 이름을 `c.log`로 변경한다. 변경 후에는 `b.log`가 사라지고 `c.log`가 남는다.

**2. 옮기기**

`mv c.log backup/`

현재 위치의 `c.log` 파일을 `backup` 폴더 안으로 이동한다. 파일을 복사하는 것이 아니라 원래 위치에서 옮기는 것이다.

`mv`는 목적지에 파일 이름을 지정하면 이름을 바꾸고, 기존 폴더를 지정하면 파일을 해당 폴더로 이동시킨다는 것을 알게 되었다.

## 막힌 것

실습 후 실제 어려웠던 부분을 기록할 예정.

- 명령어마다 옵션이 달라서 `cp -r`, `cp -i`, `rm -r`의 차이를 구분하는 데 주의가 필요했다.
- 특히 `rm`은 삭제 후 복구하기 어려우므로 경로를 확인하는 습관이 중요하다는 것을 알게 되었다.
