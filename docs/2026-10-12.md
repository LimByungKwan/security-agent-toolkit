## 오늘 설치한 것
Wireshark (Npcap 함께)

## 찾아보고 알게 된 것
보안 담당자가 패킷을 직접 열어 보는 이유는 네트워크에서 실제로 어떤 데이터가 오가는지 확인하고, 비정상적인 통신이나 문제의 원인을 찾기 위해서다.

패킷은 네트워크로 데이터를 보낼 때 일정한 크기로 나누어진 작은 데이터 단위이다.

Npcap은 Windows에서 Wireshark가 실제 네트워크 패킷을 캡처할 수 있도록 도와주는 프로그램이다.

`|` (파이프)는 앞 명령의 실행 결과를 뒤 명령으로 넘겨주는 기능이다.  
예를 들어 `tasklist | grep Code`를 사용하면 실행 중인 프로그램 중 `Code`가 포함된 줄만 볼 수 있다.

## 막힌 것
Wireshark 설치에서 Npcap이 함께 설치되어야 패킷을 캡처할 수 있어서 설치 옵션을 확인하는 부분을 주의해서 봤다.

또 `git add .`을 사용하기 전에 `git status`로 `.env`, `.venv` 같은 파일이 포함되지 않았는지 먼저 확인해야 한다는 점을 다시 확인했다.
