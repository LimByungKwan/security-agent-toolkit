# 2026-10-07 (수)

## 오늘 새로 쓴 명령
- **git init**: 현재 폴더를 Git이 관리하는 저장소로 만든다.
- **git remote add**: 내 PC의 폴더에 GitHub 원격 저장소 주소를 등록한다.
- **git fetch**: GitHub에 있는 기록을 내 PC로 가져온다. 기존 파일은 바꾸지 않는다.
- **git reset**: 현재 폴더의 Git 기록 위치를 GitHub의 기록에 맞춘다.
- **git branch -u**: 현재 브랜치와 GitHub의 원격 브랜치를 연결한다.
- **git status**: 현재 브랜치와 변경된 파일 상태를 확인한다.

## 찾아보고 알게 된 것
저장소와 내 폴더는 처음부터 자동으로 연결되어 있는 것이 아니라는 것을 알게 되었다.

내 PC의 폴더를 Git 저장소로 만든 뒤 GitHub의 원격 저장소 주소를 등록해야 서로 연결할 수 있다.

이렇게 연결하면 앞으로는 GitHub 웹에서 파일을 하나씩 올리지 않고 Git 명령어를 이용해 파일과 변경 기록을 관리할 수 있다.

## 막힌 것
`git init`, `git fetch`, `git reset`처럼 비슷해 보이는 명령이 각각 어떤 역할을 하는지 처음에는 헷갈렸다.

`git status`에서 빨간색으로 나오는 `Untracked files`가 무슨 뜻인지 잘 몰랐다. 찾아보니 Git이 아직 기록하고 있지 않은 새 파일이라는 뜻이었다.

특히 `git reset origin/main`을 실행하면 내 파일이 없어지는 것은 아닌지 걱정했지만, `--hard` 옵션을 사용하지 않으면 현재 파일은 그대로 유지된다는 것을 알게 되었다.

## 다음에 확인할 것
수정한 파일을 `git add`와 `git commit`으로 기록한 뒤 `git push`를 사용해서 GitHub에 직접 올리는 방법을 확인해 보고 싶다.
