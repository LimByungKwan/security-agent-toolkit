# 1과목 회고 (임병관)

## 내가 만든 것
- Python 기초부터 로그 처리, API·LLM 호출, AI 에이전트, 경보 요약, 마크다운 보고서, 웹훅 알림까지 이어지는 보안 자동화 파이프라인을 만들었다.
- Git과 GitHub를 이용해 실습 코드와 학습 기록도 직접 관리했다.

## 가장 어려웠던 것
- 처음에는 딕셔너리, 반복문, 파일 처리부터 정규표현식·JSON·API까지 여러 개념을 한 번에 연결해 코드를 작성하는 것이 가장 어려웠다.
- 이후에는 여러 Python 파일과 함수가 연결되는 흐름, 터미널·Git 명령어와 충돌 해결 과정이 특히 헷갈렸다.

## 리뷰에서 찾은 것과 고친 것
- 설정값 하드코딩, `timeout` 누락, 실패를 그냥 넘기는 코드, 대소문자·줄바꿈 같은 논리 오류를 찾고 설정 분리와 예외 처리로 수정했다.
- `assert` 단위 테스트와 `git status`를 활용해 코드와 파일 상태를 다시 확인하는 습관도 익혔다.

## 캡스톤에서 더 해 보고 싶은 것
- 지금까지 만든 로그 분석·LLM 요약·보고서·알림 기능을 연결해 실제 보안 관제에 가까운 자동화 도구를 만들어 보고 싶다.
- AI가 판단한 결과를 그대로 실행하기보다 사람이 최종 확인할 수 있는 구조도 더 발전시켜 보고 싶다.
