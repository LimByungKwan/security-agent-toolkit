# 1과목 회고 (ByungKwanLim)

## 내가 만든 것
- Python과 Gemini API를 활용해 보안 경보를 분석하고 위험도에 따라 분류하는 자동화 파이프라인을 만들었다.
- 여러 경보를 묶어서 요약하고, 위험도순으로 정렬한 뒤 Markdown 보고서로 저장하는 기능을 구현했다.
- 설정 파일(config.json)을 활용하고, 단위 테스트와 예외 처리를 통해 코드의 안정성을 점검했다.

## 가장 어려웠던 것
- 처음에는 VS Code의 가상환경 설정과 GitHub 저장소 연결 과정이 익숙하지 않아 어려움을 겪었다.
- 여러 Python 파일을 연결하면서 함수의 매개변수와 return 값이 어떻게 전달되는지 이해하는 것이 어려웠다.
- 오류 메시지가 발생했을 때 어떤 부분부터 확인하고 수정해야 하는지 판단하는 데 시간이 걸렸다.

## 리뷰에서 찾은 것과 고친 것
- 코드에 직접 작성된 설정값을 config.json으로 분리해 수정과 관리가 편리하도록 개선했다.
- API 요청 실패에 대비해 timeout과 try/except를 적용하는 방법을 배웠다.
- 오타, 들여쓰기, 조건문 오류 등을 수정하고 assert를 활용해 결과를 검증했다.
- 단순히 코드가 실행되는 것뿐 아니라 예상하지 못한 상황에서도 안정적으로 동작하는지 확인하는 것이 중요하다는 점을 알게 되었다.

## 캡스톤에서 더 해 보고 싶은 것
- 아직 보안 분야와 프로그래밍에 대한 지식이 많이 부족해서 구체적으로 어떤 기능을 구현할 수 있을지는 잘 모르겠다.
- 하지만 이번에 배운 보안 경보 분석 기능을 활용해 위험도가 높은 경보가 발생하면 Discord나 Slack으로 자동 알림을 보내는 기능을 만들어 보고 싶다.
- 처음부터 복잡한 시스템을 만들기는 어렵겠지만, 앞으로 더 공부하면서 작은 기능부터 하나씩 구현해 보고 싶다.
